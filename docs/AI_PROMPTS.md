# 《血狼》AI 提示词全集

> 用途：把这些提示词发给 AI（Claude / 其他大模型），即可分模块生成《血狼》的代码、数值、美术与文案。
> 使用方法：先发【总提示词】建立上下文，再按需发各模块提示词。所有提示词可直接复制使用。

---

## 一、总提示词（Master Prompt，必发）

```
你是一名资深游戏开发专家，精通 HTML5 页游开发（TypeScript + PixiJS + Vite）与多人联机服务端（Node.js + Colyseus）。

现在为我开发一款名为《血狼》的多人联机幸存者类肉鸽页游，核心规格如下：

【游戏定位】
- 类型：吸血鬼幸存者like + 肉鸽 + 4人在线合作，一局20~30分钟
- 平台：网页（桌面+手机浏览器），60fps，WebGL渲染
- 参考：吸血鬼幸存者（自动攻击/升级三选一/武器进化）、通神榜（层级难度/神通融合）、
  霓虹深渊（道具堆叠共鸣）、元气骑士（角色主动技/局外解锁）、战魂铭人（Boss弹幕/角色个性）

【核心系统】
1. 自动攻击 + 移动走位，杀怪掉经验宝石，升级出现三选一（武器/被动/筑造物）
2. 三合一合成：3个同名1级武器→1个2级，3个2级→3级（金色），合成瞬间全屏爆发特效
3. 武器进化：3级武器 + 指定满级被动 + 血月宝箱 → 传说武器（机制质变）
4. 双武器融合：两把传说武器在祭坛可融合为禁忌武器（每局限1把）
5. 筑造系统：独立4个筑造槽，可放置哨塔/图腾/城墙/熔炉，筑造物有血量、自动作战
6. 10大流派共鸣：词条带流派标签（嗜血/筑造/雷电/冰霜/毒瘟/暴击/弹幕/召唤/经济/守护），
   同标签3/5/7件触发套装质变效果；三选一权重向已持有标签倾斜
7. 高数值爽感：伤害乘区分离设计，后期伤害可达10^9量级，飘字用"万/亿"缩写，
   暴击金色大字+0.05s顿帧+屏幕震动
8. 多人联机：经验全队共享、独立三选一不阻塞他人、倒地30秒可救援、全灭才失败、
   双人流派羁绊共鸣技；怪物血量×(1+0.75×(人数-1))、数量×(1+0.35×(人数-1))
9. 局外成长：血脉天赋树（永久属性）、遗物系统（每局带3件）、血月等级30层难度、图鉴收集

【技术要求】
- 客户端 ECS 架构（bitecs），弹幕/怪物/飘字全部对象池，单屏支撑300+怪物
- 服务器权威 + 确定性模拟：怪物潮只同步波次种子与纠偏快照，不逐帧同步坐标
- 逻辑tick 15Hz广播，客户端插值到60fps；断线30秒重连，AI托管
- 代码使用 TypeScript 严格模式，模块化，附单元测试

先输出项目目录结构与技术方案，等我确认后再逐模块写代码。全程用中文注释。
```


## 九、使用建议

1. 开发顺序：总提示词 → 二（客户端）→ 四（数值）→ 三（联机）→ 七（敌潮）→ 五/六（美术文案）
2. 每个模块生成后，把实际产出的接口/数据结构回贴给 AI 再生成下一模块，保证衔接
3. 数值表生成后先跑模拟器验证（可让 AI 写一个无渲染的战斗模拟脚本，跑1000局统计通关率）
