# 《血狼》游戏设计文档（GDD）

> 版本 v1.0 ｜ 类型：多人联机 · 幸存者类肉鸽 · 页游（HTML5）
> 参考：《吸血鬼幸存者》《通神榜》《霓虹深渊》《元气骑士》《战魂铭人》

---

## 1. 一句话定位

**"血月降临，狼群求生"** —— 你是被血月诅咒的狼裔战士，在无尽涌来的怪物潮中生存 30 分钟。每局捡经验、升级三选一、合成进化武器、堆叠夸张数值，最多 4 人在线组队，打出满屏弹幕与亿级伤害数字。

## 2. 核心爽点设计（Why Fun）

| 爽点 | 实现手段 |
| --- | --- |
| 数值爆炸 | 伤害从 10 起步，后期可堆到 9 位数；暴击飘字放大+变色+屏幕震动 |
| 满屏清怪 | 单屏 300+ 怪物潮，AOE武器一次收割全屏，掉落经验宝石铺满地面 |
| 合成进化 | 三合一合成 + 武器×圣物进化，"就差一件毕业"的抽卡式期待感 |
| 流派成型瞬间 | 关键词条到手后质变：如"筑造流"拿到【狼魂图腾·王座】后炮塔全屏覆盖 |
| 组队羁绊 | 4人流派互补触发"共鸣技"，全队画面级爆发 |
| 局外养成 | 血脉天赋树 + 遗物图鉴，每局失败也有永久成长（参考霓虹深渊蛋/元气骑士材料） |

## 3. 核心循环

### 3.1 局内循环（一局 20~30 分钟）

```
选角色/遗物 → 进入地图 → 杀怪掉经验宝石 → 升级三选一（武器/被动/筑造）
→ 三合一合成 & 武器进化 → 精英/宝箱事件 → 5分钟一波Boss
→ 血月阶段（15分钟后全场狂暴）→ 最终Boss 或 无尽模式冲榜
```

### 3.2 局外循环

```
结算获得【血晶】【狼魂】→ 血脉天赋树加点（永久属性）
→ 解锁新角色/新武器进图鉴 → 提升遗物品质 → 挑战更高"血月等级"（难度层数，参考通神榜层级）
```

## 4. 角色设计（首发 8 名，狼裔主题）

每个角色 = 1 个初始武器 + 1 个主动技能（元气骑士式，有能量条）+ 1 个专属被动（战魂铭人式角色个性）。

| 角色 | 定位 | 初始武器 | 主动技能 | 专属被动 |
| --- | --- | --- | --- | --- |
| 血狼·雷加 | 近战爆发 | 裂空爪 | 血怒变身：10秒狼化，攻速+100%，吸血20% | 血量越低伤害越高（最高+150%） |
| 银月·薇拉 | 远程射手 | 银月长弓 | 月影齐射：向8方向穿透箭雨 | 暴击时50%概率不消耗攻击间隔 |
| 铁壁·戈登 | 坦克/反伤 | 碎颅重锤 | 磁石护罩：嘲讽全屏怪并反弹30%伤害 | 每100点最大生命+1%全队减伤 |
| 术狼·卡恩 | 法术AOE | 血焰法球 | 血月陨落：全屏陨石 | 技能范围+30%，范围类词条出现率翻倍 |
| 筑造师·薇薇 | 筑造流核心 | 自动哨塔 | 快速筑造：立刻免费放置一座当前等级炮塔 | 筑造物继承自身50%攻击力，上限+2 |
| 毒牙·丝卡 | DOT流 | 腐蚀飞刀 | 瘟疫领域：10秒毒雾跟随自身 | 中毒的敌人死亡时毒爆传染 |
| 赌狼·老金 | 经济/运气流 | 金币手枪（消耗金币打伤害） | 掷命骰：随机获得1个传说词条或失去10%生命 | 金币拾取范围x2，商店刷新免费1次 |
| 影刃·凛 | 暴击刺客 | 影分身短刃 | residual影：留下残影持续复制你的攻击5秒 | 背刺（怪物背向）必定暴击 |

角色通过局外图鉴解锁（血晶购买 / 成就解锁，参考元气骑士）。

## 5. 武器与合成进化系统（核心特色）

### 5.1 槽位

- 武器槽 6 个 + 被动槽 6 个 + **筑造槽 4 个**（独立，见第7章）。

### 5.2 三合一合成（自走棋式）

- 升级三选一中重复拿到同名武器：**3 个 1 级 → 1 个 2 级，3 个 2 级 → 1 个 3 级（金色）**。
- 合成瞬间全屏结算一次该武器的"合成爆发"（例如裂空爪合成时全屏爪击），强化爽感反馈。

### 5.3 武器进化（吸血鬼幸存者式）

**3 级武器 + 指定满级被动 + 击败精英掉落的「血月宝箱」→ 进化为传说武器**，形态与机制质变：

| 基础武器 | 搭配被动 | 进化后 | 效果质变 |
| --- | --- | --- | --- |
| 裂空爪 | 狂怒之心（攻速） | 千爪风暴 | 近身持续旋风，吸附怪物绞杀 |
| 银月长弓 | 鹰眼（暴击率） | 弑神狙 | 每3秒锁定全屏血量最高者，造成2000%必暴击 |
| 血焰法球 | 智慧秘典（范围） | 血月熔核 | 绕身巨型火球，接触怪物连锁爆炸 |
| 自动哨塔 | 工程蓝图（筑造强化） | 狼魂图腾·王座 | 全部筑造物射程翻倍并连锁闪电 |
| 腐蚀飞刀 | 剧毒腺体 | 瘟疫风暴 | 毒雾覆盖1/3屏幕，中毒层数无上限 |
| 金币手枪 | 貔貅袋（金币掉率） | 财神加特林 | 攻速与金币持有量挂钩，弹幕全屏 |
| 影分身短刃 | 疾风靴（移速） | 千影绝杀 | 移动路径留下刀阵，移速转化为伤害 |
| 碎颅重锤 | 巨人腰带（体型/击退） | 大地粉碎者 | 每次落锤地裂，范围内怪物眩晕+碎甲 |

### 5.4 双武器融合（通神榜式"神通组合"）

两把**进化武器**在祭坛事件处可融合为"禁忌武器"（每局限1把），例如：

- 弑神狙 + 千影绝杀 = **影狙·无我**：残影也会开狙。
- 血月熔核 + 瘟疫风暴 = **腐蚀之星**：火球留下毒岩浆地板。
- 狼魂图腾·王座 + 财神加特林 = **军工厂**：炮塔改装为加特林塔，攻击掉金币。

## 6. 流派（Build）设计 —— 首发 10 大流派

词条（被动/圣物）带**流派标签**，同标签收集越多触发"流派共鸣"（3/5/7 件套效果，参考霓虹深渊道具堆叠）：

| 流派 | 核心玩法 | 7件共鸣效果（成型质变） |
| --- | --- | --- |
| 嗜血流 | 吸血、低血高攻、以伤换伤 | 溢出治疗转化为"血盾"，血盾爆炸伤害 |
| 筑造流 | 炮塔/图腾/城墙自动作战 | 筑造物获得你100%词条加成并自动升级 |
| 雷电流 | 连锁闪电、麻痹 | 闪电必定连锁至8个目标，麻痹怪互相传电 |
| 冰霜流 | 减速、冻结、碎冰 | 冻结怪被击碎时对全屏冰爆 |
| 毒瘟流 | DOT叠层、传染 | 毒伤可以暴击，死亡毒爆范围x3 |
| 暴击流 | 暴击率/暴伤无限堆叠 | 暴击率超过100%的部分转化为暴伤 |
| 弹幕流 | 弹体数量、反弹、穿透 | 所有子弹反弹+1，弹体数量+50% |
| 召唤流 | 狼灵伙伴、亡灵大军 | 召唤物死亡时分裂为两只小狼灵 |
| 经济流 | 金币转伤害、赌博事件 | 每持有100金币全属性+1%，击杀掉金币翻倍 |
| 守护流 | 护盾、反伤、荆棘 | 受击时100%反弹伤害并全队分摊治疗 |

**设计规则**：三选一权重向"已持有标签"倾斜（越玩越成型），但每局保底出现1个跨流派选项防止僵化。

## 7. 筑造系统（差异化卖点）

- 独立**筑造槽 4 个**，通过升级三选一中的"筑造牌"获得。
- 放置逻辑：获得后进入 3 秒放置模式，自由选点；也可托管自动放置。
- 筑造物有血量，可被怪物攻击摧毁，摧毁后 30 秒返还为可再放置状态。

| 筑造物 | 功能 | 3级效果 |
| --- | --- | --- |
| 狼牙哨塔 | 自动索敌射击 | 三连发+穿透 |
| 血祭图腾 | 范围内队友吸血光环 | 光环内伤害+25% |
| 荆棘城墙 | 阻挡怪物+接触伤害 | 怪物撞墙眩晕 |
| 磁能虹吸柱 | 大范围吸取经验/金币 | 拾取时10%概率复制掉落物 |
| 狼魂熔炉 | 每30秒免费重铸一次三选一 | 重铸必出稀有以上 |
| 雷暴发生器 | 周期性全屏放电（需充能） | 队友攻击可为其充能 |

**筑造流成型体验**：薇薇 + 王座进化 + 筑造7件共鸣 = 玩家只需走位捡经验，12+ 座满级炮塔自动清屏——"塔防化"的挂机爽感。

## 8. 高数值模型（爽感的数学基础）

### 8.1 伤害公式

```
最终伤害 = 基础伤害 × (1+攻击力%) × (1+流派增伤%) × 暴击倍率 × 易伤系数 × 血月等级压制系数
```

- 所有加成**乘区分离**，保证多流派词条叠加时指数增长（这是"高数值"的来源）。
- 数字显示：超过 1 万显示"1.2万"，超过 1 亿显示"3.5亿"，暴击金色大字+顿帧 0.05s。

### 8.2 成长曲线

| 时间 | 玩家DPS量级 | 怪物血量量级 | 体验目标 |
| --- | --- | --- | --- |
| 0-5min | 10²  | 10² | 学习期，逐渐站稳 |
| 5-12min | 10³~10⁴ | 10³ | 首次合成/进化，第一次质变 |
| 12-20min | 10⁵~10⁶ | 10⁵ | 流派共鸣成型，割草期 |
| 20-30min | 10⁷~10⁹ | 10⁷ | 血月狂暴，双方数值军备竞赛 |

- 经验需求按 `20 × 1.18^level` 增长；怪物血量按 `HP₀ × 1.13^分钟 × 血月等级系数` 增长。
- **保底爽感**：无论Build强弱，15分钟后必然能一击清杂兵（杂兵血量刻意低于玩家DPS下限）。

### 8.3 血月等级（局外难度层，参考通神榜）

通关后解锁下一层（共 30 层）：怪物属性↑、新词缀（分裂/自爆/诅咒光环），同时**掉落品质与结算奖励↑**。高层排行榜按通关时间+击杀数结算。

## 9. 多人联机设计（2~4 人）

### 9.1 房间与匹配

- 房主创建房间（可设密码/好友链接直接进，页游一键分享URL加入）。
- 快速匹配按血月等级分段。断线30秒内可重连，角色由AI托管走位。

### 9.2 合作机制

- **经验共享**：任何人拾取经验，全队获得100%（避免抢资源）。
- **独立三选一**：升级时各自暂停选择，不阻塞他人（选择界面出现时自身无敌1.5秒，游戏不全局暂停）。
- **倒地救援**：倒地进入30秒濒死，队友引导3秒救起；全灭才失败。每波Boss击杀后全员复活。
- **羁绊共鸣技**：两名玩家流派达到5件共鸣时解锁双人组合技（例：雷电+冰霜 = 超导风暴，全屏冻结后闪电伤害x3），由任意一人主动释放，60秒CD。
- **怪物缩放**：怪物血量 × (1 + 0.75 × (人数-1))，数量 × (1 + 0.35 × (人数-1))，保证多人比单人更爽而不是更累。

### 9.3 轻竞争彩蛋

- 局内实时"伤害占比"面板；结算MVP（伤害/救援/筑造/拾取四个维度），激励不同定位。

## 10. 关卡与敌人

### 10.1 首发 3 张地图

| 地图 | 主题 | 机制 |
| --- | --- | --- |
| 血月荒原 | 新手图，开阔 | 周期陨石带（踩线躲避） |
| 沉沦教堂 | 室内窄道 | 可破坏长椅掉落补给；窄道利好弹幕反弹流 |
| 霓虹废都 | 赛博废墟（致敬霓虹深渊） | 随机传送门通向"挑战间"：限时杀怪拿传说词条 |

### 10.2 敌潮设计

- 每 30 秒一小波、5 分钟一Boss、15 分钟血月狂暴（全怪提速+变红）。
- 精英词缀池：分裂、自爆、磁力（吸走经验石）、诅咒（禁用1个武器槽10秒）、镜像（复制玩家武器）。
- Boss 战设计弹幕躲避（战魂铭人式），Boss掉落血月宝箱（进化材料）+ 保底传说词条。

### 10.3 局内事件（霓虹深渊/元气骑士式房间感）

魔女商店（金币购词条/重抽/移除词条）、献祭祭坛（扣血换传说/双武器融合）、狼神雕像（赌运气三选一）、被诅咒宝箱（打完守卫波次开箱）。

## 11. 局外成长

- **血脉天赋树**（血晶消耗）：攻击/生命/移速/幸运/复活次数/初始重抽次数等 40+ 节点。
- **遗物系统**（狼魂抽取+图鉴升星）：每局带 3 件，如"初始自带1级哨塔""第一次进化免材料"。
- **图鉴收集**：武器/词条/怪物/融合配方，收集度奖励血晶（收集癖驱动）。
- **每日血月试炼**：固定种子，全服同条件冲榜。

## 12. 商业化（页游友好，非付费墙）

外观（狼形态皮肤/飘字样式/拖尾）、月卡（结算血晶+20%）、广告位（页游端看广告复活一次/双倍结算，可选）。**不卖数值词条**，保证肉鸽公平性。

## 13. 技术架构（页游 + 联机）

```
客户端 (TypeScript + PixiJS + Vite)
  ├─ 渲染层：Sprite批处理，对象池（弹幕/飘字/怪物），WebGL
  ├─ 逻辑层：ECS（bitecs），确定性随机（种子同步）
  └─ 网络层：Colyseus client，状态插值 + 本地预测

服务端 (Node.js + Colyseus)
  ├─ Room：一局一房，服务器权威（怪物刷新/伤害结算/掉落）
  ├─ Tick：逻辑 15Hz 广播，客户端 60fps 插值
  ├─ 抗作弊：升级选择、伤害均由服务端校验
  └─ 持久化：PostgreSQL（账号/图鉴/天赋）+ Redis（匹配/排行榜）
```

**海量实体同步策略**：怪物潮不逐帧同步坐标——服务器只同步"波次种子+目标玩家"，两端用相同确定性寻路模拟，仅同步死亡/伤害事件与周期性纠偏快照（这是页游能扛住300+怪联机的关键）。
