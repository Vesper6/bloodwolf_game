# 血狼 (Blood Wolf)

一款支持多人联机的**幸存者类肉鸽（Roguelike Survivor-like）页游**。

- 参考对象：《吸血鬼幸存者》《通神榜》《霓虹深渊》《元气骑士》《战魂铭人》
- 核心卖点：**高数值爽感 · 武器合成进化 · 筑造流 · 多流派Build · 4人在线合作**
- 平台：网页（HTML5，桌面/手机浏览器均可玩）

## 快速开始（M0 可玩原型）

```bash
npm install
npm run dev      # 开发模式，浏览器打开提示的地址
npm run build    # 产物输出到 dist/，可直接静态部署

# 联机服务器（可选，单人模式不需要）
cd server && npm install && npm start   # ws://localhost:2567
```

**操作**：WASD / 方向键移动，空格释放【血怒】，手机端触屏拖动。目标：生存 15 分钟。

**联机**：启动服务器后，主界面点「创建联机房间」，把地址栏自动生成的 `?room=房号` 链接发给好友，
好友打开点「加入房间」即可（最多 4 人）。

**M0 已实现**：血狼·雷加（低血高攻被动 + 血怒主动技）、3 把武器（裂空爪/银月长弓/血焰法球）、
升级三选一（含稀有度与合成权重倾斜）、三合一合成 + 全屏爆发、8 种被动词条、
怪物潮成长曲线、精英怪、双 Boss（5/10 分钟）、伤害飘字（万/亿缩写 + 暴击顿帧震屏）、经验宝石合并优化。

**M1 已实现**：
- **武器进化链**：3级武器 + 对应被动Lv3 + 精英/Boss掉落的血月宝箱 → 传说武器
  （裂空爪→千爪风暴·旋风吸附绞杀 ｜ 银月长弓→弑神狙·3秒锁定最高血量20倍必暴击 ｜ 血焰法球→血月熔核·连锁爆炸）
- **筑造系统**：狼牙哨塔（自动索敌）/ 血祭图腾（治疗光环）/ 磁能虹吸柱（吸取经验），
  有血量、会被怪物磨损摧毁，同名再选=升级+修复+移位
- **流派共鸣**：嗜血/暴击/筑造三系标签，3/5/7 件触发套装质变
  （如暴击VII：暴击率溢出转暴伤 ｜ 筑造V：筑造物完整继承攻击力加成）
- **公告走马灯**：进化/共鸣/筑造事件全屏播报

**M2 已实现（2~4 人联机合作）**：
- 原生 ws 房间制服务器：怪物刷新/血量/掉落**服务器权威**，客户端上报命中批次（10Hz）
- 怪物快照同步（10Hz）+ 客户端插值；怪物血量/数量按人数缩放（×1.75 / ×1.35 每加一人）
- **经验全队共享**：任何人拾取宝石，服务器广播全队入账
- **独立三选一**：联机中选卡不暂停游戏，选卡期间接触伤害免疫
- **倒地救援**：血量归零进入濒死，队友靠近 3 秒救起（复活 50% 血量），全灭才失败
- 队友渲染：蓝色调狼形+名字+血条插值同步；宝箱先到先得服务器仲裁
- 房号邀请链接（`?room=XXX`）一键加入

**M3 已实现（内容与局外成长）**：
- **4 名可选角色**（各自初始武器/专属被动/主动技）：
  血狼·雷加（低血高攻+血怒狼化）｜ 银月·薇拉（暴击射手+16向月影齐射）｜
  筑造师·薇薇（开局自带哨塔+快速筑造）｜ 术狼·卡恩（范围+30%+全屏血月陨落）
- **血月等级 1~30 层**：怪物血量 ×1.25^层数，通关立即解锁下一层（联机取房主层数）
- **血脉天赋树**（localStorage 存档）：狼牙/狼血/狼步/狼运 各 10 级，血晶购买；
  狼运提升三选一稀有度权重
- **血晶结算**：击杀/10 + 分钟×5 + 胜利 100×层数
- **无尽模式**：生存 15 分钟通关后不结束，怪物继续膨胀，冲击更高生存纪录

**M4 已实现（深度机制）**：
- **禁忌融合**（GDD 5.4）：持有两把进化武器后拾取血月宝箱触发融合——
  双效果全保留合为一把（影狙·无我 / 千爪熔核 / 腐蚀之星），攻击力+30%，腾出武器槽
- **Boss 弹幕战**（战魂铭人式）：Boss 周期释放 14 向环形弹 + 5 连追踪扇形弹，
  需要走位躲避（选卡/倒地时免疫）
- **血月狂暴**：无尽模式中全体怪物提速 40% 并变红

## 技术选型（页游）

- 客户端：TypeScript + PixiJS（渲染）/ Phaser 3（可选），Vite 构建
- 服务端：Node.js + 原生 ws（轻量房间制消息同步），支持 2~4 人联机
- 同步模型：服务器权威 + 客户端预测；怪物由服务器统一刷新与寻路（低频tick + 客户端插值）

**稳定性加固**：
- 服务端：心跳 ping/pong（30秒无响应断开）、每消息 try/catch 隔离、64KB 载荷上限、
  房间逻辑异常互不影响、空房 60 秒自动回收、进程级异常兜底
- 客户端：断线自动重连（指数退避8次，携带 sessionId 恢复同房间会话）、
  welcome 前消息队列防时序竞态、渲染帧异常保护（单帧报错不中断游戏）
- 单机：局内进度每3秒+关页自动存档，刷新可「继续上局」
